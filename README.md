> ### Реакция антивирусов
>
> Антивирус может отреагировать на WinDivert.  
> Для работы zapret WinDivert перехватывает и фильтрует сетевой трафик.
> Этот инструмент способны использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает файлы WinDivert потенциально опасными либо относит их к хакерским инструментам. В результате файл удаляется и попадает в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с запретом в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). В Kaspersky, например, это настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете последствия и умеете правильно настроить исключения, предпочтителен вариант с исключением; при сомнениях отключите обнаружение PUA.

## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Получите zip/rar-архив с [последнего релиза](https://github.com/storagebuilderhem/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". Пользователям 7-Zip или PeaZip выполнять этот шаг не требуется.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите подходящий файл:
    * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Для установки стратегии в автозапуск используйте **`service.bat`** -> `Install Service` -> выберите нужную стратегию.

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc).</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения необходимо перезапустить стратегию.**  
  Значение в скобках показывает текущий статус: включено или выключено.
  - **`IPSet Filter`** — включить или выключить обработку сервисов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается состояние:
    - `none` — ни один IP не проверяется;
    - `loaded` — IP сверяется со списком;
    - `any` — под фильтр попадает любой IP.  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения Discord к голосовому чату.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`;
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/storagebuilderhem/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию

- Откройте командную строку с правами администратора.
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и запустите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Откройте файл `hosts` в созданном каталоге текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленный аналогичный фрагмент.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если веб-версия не заработала, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/storagebuilderhem/tg-ws-proxy) или любым публичным прокси.

### Обход перестал работать

> [!IMPORTANT]
> **Стратегия не обязательно сохраняет работоспособность навсегда.**
> Обнаружение стратегии может произойти не сразу: некоторое время она работает, а затем перестаёт.
> Здесь собрано много разных вариантов. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся и измените её параметры. О параметрах можно прочитать [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте, нет ли ошибок.
- Удостоверьтесь, что нужный ресурс присутствует в списках доменов или IP.
- Переберите другие стратегии, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/storagebuilderhem/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце выберите Y.
- Удалите старую папку с запретом.
- Загрузите свежую версию [со страницы релизов](https://github.com/storagebuilderhem/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву, откройте свойства и, если внизу справа есть "Разблокировать", отметьте пункт, нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска, избегая пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте ресурсы. Если интернет не работает, закройте программу по значку замка на панели задач и попробуйте следующую стратегию.
- После выбора рабочего варианта установите его в автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом запрете

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался в службах

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Затем остановите и удалите службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если рабочая стратегия раньше перестала помогать, переберите остальные.
- См. также [#251](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузер тоже не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/storagebuilderhem/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

При этом `ipset any` способен нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно: определите все IP, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

- Опишите её [здесь](https://github.com/storagebuilderhem/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Нужные адреса можно добавить в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети.
  - Файлы **`*-user.txt`** автоматически создаются при первом запуске `zapret` либо `service.bat`.
