>
> Добавьте каталог с zapret в исключения антивируса либо отключите проверку PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете, как работают исключения, безопаснее настроить исключение для нужной папки; при отсутствии уверенности рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (Cloudflare может быть заблокирован)
    * В Windows 11 Secure DNS можно включить в параметрах самой ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/storagebuilderhem/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется

4. Распакуйте архив в путь без кириллических и специальных символов

5. Запустите необходимый файл
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Для установки автозапуска выберите **`service.bat`** → `Install Service` → подходящую стратегию

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты — ALT, FAKE и другие, пока не найдёте подходящий**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  После смены этого параметра стратегию необходимо перезапустить.  
  В скобках показывается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
  Это пригодится при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается состояние:
    - `none` — ни один IP не проверяется
    - `loaded` — проверяется наличие IP в списке
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает его работоспособность
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход); его можно увидеть на панели задач.  
Если winws.exe не запустился, обратитесь к [#522](https://github.com/storagebuilderhem/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и запустите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Откройте текстовым редактором от имени администратора файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный фрагмент
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/storagebuilderhem/tg-ws-proxy) либо с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Стратегия может некоторое время справляться с обходом, а затем перестать работать после обнаружения.
> В репозитории собрано много стратегий. Если готовые варианты не помогают, создайте собственную, взяв одну из них за основу и изменив параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` → `Run Diagnostics` проверьте, нет ли ошибок

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/storagebuilderhem/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Запустите `service.bat` → `Remove Services`
- В `service.bat` выберите `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y
- Удалите папку zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/storagebuilderhem/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой мыши на архиве и откройте свойства. Если внизу справа есть "Разблокировать", включите этот пункт, нажмите "Применить" и затем "ОК"
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- По очереди запускайте разные скрипты `general` и проверяйте сайты. Если ресурс не работает, закройте программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочей стратегии установите её в автозапуске: `service.bat` → `Install Service` → нужная стратегия

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные ресурсы.

### Античит ругается на WinDivert

- Воспользуйтесь инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. В командной строке Windows узнайте имя службы (Win+R → `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- См. также [#251](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- Откройте `service.bat` → `Run Diagnostics` и выполните очистку кэша Discord
- Проверьте Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузерная версия тоже не подключается, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/storagebuilderhem/tg-ws-proxy)
- Также можно использовать бесплатные MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсальной последовательности:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

У режима `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не держите его включённым постоянно. Лучше выяснить IP-адреса, используемые игрой, и добавить их в `ipset-all.txt`

Если результат не изменился, создайте обсуждение в разделе [Discussions](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/storagebuilderhem/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети-исключения
  - Файлы **`*-user.txt`** будут созданы автоматически при первом запуске `zapret` или `service.bat`
